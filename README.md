# 고전 번역 및 각색 프로젝트

구텐베르크(Project Gutenberg) 영문 고전 소설을 초등학교 5~6학년 눈높이에 맞춰 한국어로 번역·각색하는 개인 프로젝트입니다.

## 사용 방법

1. 새로 번역하고 싶은 작품의 영문 원문(.txt)을 `source/`에 넣습니다.
2. Claude Code로 이 저장소를 열고, 원문을 번역해 달라고 요청합니다.
   - 작업 규칙(문체, 압축률, 청크 분할 방식, 완성본 자동 병합 등)은 [CLAUDE.md](CLAUDE.md)에 정의되어 있어 별도 설명 없이도 동일한 방식으로 진행됩니다.
3. 작업이 끝나면 프로젝트 루트에 `<작품명>_완성본.md` 파일이 자동으로 생성/갱신됩니다.

## 폴더 구조

```text
source/        # 원본 구텐베르크 텍스트 (.txt)
chunks/        # 약 10,000자 단위로 분할된 원문
translated/    # 청크별 번역·각색본 (trans_NNN.md)
glossary.md    # 인명, 지명 등 고유명사 통일표
CLAUDE.md      # 번역 스타일 및 작업 프로세스 규칙
```
